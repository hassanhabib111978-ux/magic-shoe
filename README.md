# Magic Shoe

Original mobile adventure and puzzle game.

## MVP 0.2
- Explore the first area
- Solve the first puzzle
- Discover the magical shoe
- Unlock the hidden-step mechanic
- Reveal a secret path
- Save progress locally
- Touch controls for Android plus keyboard controls

## Product direction
Shoe → Wand → Invisibility Hat → Ring → Magic Lantern → expandable adventures.

The project is designed as an original IP with scalable gameplay and future optional monetization. Ads and payments are intentionally excluded from the first playable build.
