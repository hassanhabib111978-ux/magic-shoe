# الحذاء السحري — Web MVP

نسخة اختبار تعمل مباشرة من المتصفح، دون الحاجة إلى محرر Godot.

## التشغيل
فعّل GitHub Pages للمستودع من Settings → Pages → Deploy from branch → main → /(root) → Save.

بعدها افتح رابط GitHub Pages للمستودع.

## التحكم
- لمس/سحب الشاشة: حركة الشخصية.
- زر «تفاعل»: حل اللغز، أخذ الحذاء، ثم كشف الطريق السري.
- لوحة المفاتيح اختيارية على الهاتف عند توفرها.

## مسار الاختبار
1. اقترب من حجر اللغز واضغط «تفاعل».
2. اتبع النجوم إلى الحذاء واضغط «تفاعل».
3. اذهب إلى «طريق خفي» واضغط «تفاعل».
4. تظهر رسالة أن مهمة العصا السحرية أصبحت مفتوحة.

هذه نسخة اختبار مبكرة؛ لا إعلانات ولا مدفوعات فيها.
